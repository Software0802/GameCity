# showcase_max credits

All third-party resources in this package are **CC0 1.0** from [Poly Haven](https://polyhaven.com) (license: https://polyhaven.com/license).
They were downloaded with `tools/fetch_polyhaven.py` through the public API `https://api.polyhaven.com/files/<asset_id>`.
Authors and names below come from `https://api.polyhaven.com/info/<asset_id>`.

Textures are used as albedo (`_diff.jpg`), packed AO/roughness/metal (`_arm.jpg`) and OpenGL normal (`_nor.jpg`).
No map is larger than 2K. Everything else in the package (road markings, facades, windows, lamps, cars, trees, props, overlays) is generated by code.
