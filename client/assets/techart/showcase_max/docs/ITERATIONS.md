# ITERATIONS

每一轮：渲染 → 用 Read 打开 PNG → 写下这张图最差的三个地方 → 修 → 再渲染。
中间图在 scratchpad（不进仓库），交付图在 `../preview/`。「渲染」列写的是被审视的图。

| 轮次 | 被审视的图 | 最差的三个地方 | 改了什么 / 为什么 |

| 0 | 管线探针：灰盒加地面，3840×2160，正交微斜 | 1) 只渲出天空，相机放在了焦点前面而不是后面；2) 正交相机在 300 m 外，SDFGI 阴影区纯黑；3) `viewport_get_measured_render_time_gpu` 在 Metal 上恒为 0 | 相机改为 `focus + basis.z * dist`。渲染一律走固定尺寸 `SubViewport`，在 2560×1664 Retina 屏上 1080p 和 4K 都精确。GPU 计时在 Metal 上读不出，帧时改用 `force_draw` 60 帧吞吐，另记 `TIME_PROCESS`。 |
| 1 | `s01_hero_day` 第一版（道路、地块、建筑，无道具、无 overlay） | 1) 光照平：环境光过强，玻璃塔发棕；2) 屋顶空调箱带两个黑色风扇圆盘，在阵营徽章旁像卡通眼睛；3) 草地荧光黄绿、树冠发白，街上空无一物 | 加 overlay 层（分区地块板、阵营角标、领地幕、屋顶徽章、电力圈、拥堵脉冲）、路灯、红绿灯、行道树、停放车辆、长椅。太阳 3.1、天空环境 0.6，对比度 1.1。幕墙改成介电蓝玻璃（俯视下金属玻璃只会反射黑街道，永远是黑的）。空调箱改成浅色百叶箱，屋顶留 3.6 m 净空给徽章。树冠与草地压向调色板的 ground 色。 |
| 2 | `s01_hero_day`、`s03_near_block`、`s00_cinematic_*`、`s02_far`（道具加完后） | 1) 电影镜头相机落在楼体里，景深把整帧糊掉；2) 街区在左边缘被硬切，A 领地被边界截断；3) 玻璃塔幕墙后面透出粉、橙、蓝的房间 | 地图扩到 18×18 格，领地半径收进地图内。景深参数改成相对焦距（近 0.55×、远 1.12×）。办公类室内用中性色板。电影镜头抬到屋顶之上。远景加格网和 8 格兴趣区块线。 |
| 3 | `s01_hero_dusk`，随后做逐分量消融（太阳 / 环境 / 灯池 / OmniLight 单独开） | 1) 黄昏整张图橙粉过曝，环境光关掉后画面仍亮；2) 零光源时地面仍被照亮；3) 灯池加叠加的路面变成一片白 | 消融结果：`PanoramaSkyMaterial` 把 HDRI 里的太阳盘（亮度上万）原样写进 radiance，粗糙表面于是在 DirectionalLight3D 之外又反射了一个更强的太阳（双重光）。改成自写 sky shader：radiance 通道钳到 3.0（黄昏 2.4），可见背景钳到 40，radiance 另乘 0.5–1.0，地平线以下换成暗地面色。灯池增益 0.5，OmniLight 能量 2.2→1.4。 |
| 4 | `s01_hero_day`，SDFGI 开 / 关对比 | 1) 差分图平均 0.0：SDFGI 在 420 m 外的正交相机下完全没生效；2) 阴影内死黑；3) 近 100 帧才收敛 | SDFGI 级联以相机为中心，相机远则单元太粗。游戏镜头把相机拉到 150 m（近景 100 m），`sdfgi_cell` 按镜头设。随后试 `VoxelGI`：不依赖相机，烘一次复用，细分 512 效果明显更干净。截图档 GI 选 VoxelGI（烘焙 6–13 s），交互档用 SDFGI 3 级联。 |
| 5 | `s03_near_block`、`dev_street_*`、`dev_facade_*` | 1) C 区墙面（concrete_wall_003）像脏大理石；2) 所有平屋顶一律黑色；3) 阳台玻璃、车身线条、树冠是一团色块 | 换 `grey_plaster` 与 `rectangular_facade_tiles`。平屋顶分碎石、浅色防水层、绿化屋顶三种。树冠加叶片噪声镂空。车身加门缝与腰线。窗框加 7 cm 窗洞倒角法线。 |
| 6 | `s03_near_block` 的 overlay 层 | 1) 阵营色发白，A 的薄荷绿几乎成了白色；2) R/C/I 分区色看不出（0.3 透明度压在草地上成了橄榄色）；3) 电力覆盖和拥堵条是奶油色 | 实测 Godot 4.7.2 ACES（白点 6、对比度 1.1）后，在 GDScript 里复刻公式（与实测输出逐像素一致，见 REPORT「调色板还原」），数值反求让最终画面落在调色板 hex 上。overlay 顶点色改存调色板槽位，shader 查每个预设的补偿表。分区色加 0.9 m 实心边框。电力整格色透明度 0.085→0.034（0.085 把整张图染成棕褐色）。 |
