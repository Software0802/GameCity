# GameCity 设计 v2

负责人志坤于 2026-10-08 决定。本文件取代 v1 brief 中与之冲突的锁定；v1 文档保留作历史，其中的数据类型（地块、边、兴趣区、指令）继续有效。

## 一句话

两阵营持久世界：先经营城市，再用城市的钱养军队，摧毁对方政府核心者胜。一轮 7 天，服务器常驻，玩家可随时下线。

## 取代 v1 的锁定

| v1 | v2 |
| --- | --- |
| 一局一城，不持久化 | 服务器持久化：定期快照，重启不丢进度 |
| listen-host | 专用无头服务器（阿里云 ECS），客户端只是客户端 |
| 30–45 分钟 | 一轮 7 天，`--round-seconds` 可配，按墙钟计时 |
| 64×64 | **128×128**，兴趣区仍 8×8（16×16 个块） |
| 永不改对方数据 | 军事阶段按交战规则摧毁和占领；城市阶段仍不可直接改对方 |
| 计分 40/30/30 定胜负 | 军事上线后胜负 = 摧毁政府核心，分数用于排行与轮回结算；军事上线前仍按分数定胜负 |
| 不做车辆网格 | 士兵、坦克、导弹是游戏单位 |
| 不做市民 | 人口与技术人员是数值，可在阵营间迁移；不渲染个体 |

不变：2 阵营、2–4 人、服务器权威、客户端只发意图、正交道路、M2 阶段只有电力、程序化中等写实 + Forward+ + CC0。

## 已定的规则

### 经济（M2）
- 预算是节奏器。开局一笔资金；每秒收入 = 人口税 + 商业税 − 电站维护。
- 占领地块花钱且随已占数量递增；修路固定价；电站贵；分区免费；拆除免费。
- 资金不足时指令被拒（`INSUFFICIENT_FUNDS`），没有破产惩罚。
- 税率是玩家指令（`SetTaxRate`），影响收入和满意度。
- 财政分 = 结束时的资金。

### 成长（M2）
- 每阵营一个全局需求三角：R 需求看岗位缺口，C 和 I 需求看人口。
- 每格满意度由有路、有电、本区需求是否为正、拥堵、污染共同决定。
- 满意度高持续一段时间升一档，低持续一段时间降一档，档位 0–2。
- 人口按 R 格档位加权；岗位按 C/I 格档位加权。
- 工业格产生污染，按半径扩散，不认边界。拥堵是边上的本地负载模型，不认边界。
- 不做逐格寻路和车流。

### 电力（M2）
- 电站有覆盖半径和容量。覆盖区内建筑档位之和超过容量即欠压：该电站覆盖区满意度减半并发警报。

### 危机（M2）
- 轮次进行到一半时触发一次电网风暴：持续 90 秒，所有电站容量减半。两边同一事件。

### 跨界影响与迁移（M3）
- 污染和拥堵跨界是前期轻对抗。
- 技术人员是第二类人口，由 C/I 的高档建筑产生，提升工业产能和军事装备质量。
- 人口和技术人员按双方满意度与税率之差跨界迁移。

### 军事（M5）
- 政府核心是每个阵营的核心建筑，有生命值；核心被毁即本轮出局。
- 兵营出士兵，坦克厂出坦克（需要工业产能），导弹井是后期战略打击，有冷却和落点预警。
- 军队按分钟级行军，战斗按分钟级自动结算；防御塔和驻军自动作战。不做即时微操。
- 被摧毁的建筑变废墟，地块归中立；进攻方部队驻扎在相邻格时可以占领。

### 离线保护（M5）
- 慢节奏军事加自动防御为主；离线超过 8 小时自动开护盾，护盾期间不能进攻也不会被进攻。

### 轮回（M6）
- 有上限的继承：赢家保留国库的一部分和政府等级；输家迁到新区域重建并带保护期；每轮地图向外扩一圈中立地。

### 身份
- 首次加入时服务器签发令牌，客户端存本地，附显示名。服务器只存令牌哈希。未知令牌视为新玩家。
- 同阵营的多名玩家共享国库和权限；大厅与阵营选择在 M3。

### 操作
- 鼠标为主：左侧工具栏（占领、分区 R/C/I/清除、道路、电站、拆除、税率），左键施放，拖动连画，右键取消，滚轮缩放，WASD 或边缘平移。
- HUD：资金、每秒收入、人口、剩余时间、双方总分、最近警报、危机横幅。

## 节奏

- sim tick 仍是 1 秒。所有成长和经济时长 = 基准 × pace，`--pace` 配置；测试轮 pace 0.01，正式轮 1.0。
- 轮次结束时间 `round_ends_at_unix` 写进存档和 `MatchStart`，服务器停机不延长轮次。

## 里程碑

| 里程碑 | 内容 | 验收 |
| --- | --- | --- |
| **M2A 基础设施** | 专用服务器、令牌握手、快照与恢复、128 地图、鼠标客户端（纯色几何）、轮次时钟、按分数结束。规则沿用 v1，无花费 | 两个客户端在云机上建造，断线，服务器重启，各自重连回到自己的城 |
| **M2B 模拟** | 经济与成本、税率、RCI 成长、污染、拥堵、电力容量、电网风暴 | 没钱的阵营收到 `INSUFFICIENT_FUNDS`；有路有电的 R 格升到 1 档；超载电站欠压 |
| **M3 轻对抗** | 跨界影响的平衡、技术人员、迁移、排行 | 工业贴边能压低对方满意度并引发迁移 |
| **M4 画面接入** | showcase 的程序化生成器按 8×8 块接到真实对局数据 | 真实对局画面达到 showcase 交互档 |
| **M5 军事** | 政府核心、兵营、坦克厂、防御、行军与结算、占领、离线护盾 | 一方摧毁对方核心，轮次结束 |
| **M6 轮回** | 导弹、有上限继承、迁移重建、地图扩张 | 第二轮开局符合继承规则 |

## 原则

- **质量优先**（负责人原话）。每条规则都有无头测试；合并的代码里没有占位 TODO；每个 worker 交付前自己跑通全部冒烟。
- 生产变更（部署、停服、改数据）每次都要负责人确认，脚本不自动执行。
