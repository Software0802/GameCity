## 怎么看效果

```bash
tests/run_local_demo.sh          # 起本机服务器 + 一个窗口客户端（阵营 A）
tests/run_local_demo.sh --two    # 两个客户端，A 和 B 各一个窗口
```

默认 pace 0.05（升档约 6 秒，便于观看）。操作：工具栏 1–8，左键施放，拖动连画分区和道路，右键或 Esc 取消，税率滑块，WASD 或屏幕边缘平移，滚轮缩放。关掉窗口后服务器用 stop 文件存档退出；`./.demo/` 存着存档和身份文件，删掉即重新开局。

建议一试的流程：占领几格 → 分区 R 和 C → 拖一条路把它们连起来 → 放一座电站 → 看 HUD 的人口与收入涨、建筑长高 → 把税率拉到 30% 看满意度掉档 → 关掉客户端再开，回到同一座城。

## 这一晚的集成决定

- `--free-build` 定义为沙盒：不扣建造费、不扣维护费、国库冻结。
- `DEMAND_GATE_CLOSED = 0.3` 进 `SliceConstants`。
- 危机结束时间由服务器调度器传给模拟，不乘 pace。
- 无头 Godot 收不到 SIGTERM（探针实测硬杀），优雅停机改为 stop 文件；systemd 的 `ExecStop` 必须 touch 该文件。部署文档已改。
- `--start-treasury` 加进服务器参数，供测试和开局设定。
- 存档打包默认排除 `client/assets/techart`，主机解包后跑一次 `--import`。

## 没做的与已知问题

- 云机部署：脚本就绪（`deploy/deploy.sh --dry-run` 全流程可打印），**未执行**，等您确认后再上。

- HUD 是英文（默认字体不含 CJK）。

- 完整打磨清单在 `docs/plans/m2-city-phase.md`「M2 打磨项」。
